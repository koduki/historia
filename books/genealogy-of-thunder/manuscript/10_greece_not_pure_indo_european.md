# 第10章　ギリシアは「純粋な印欧神話」ではない

## オリュンポスの混血性

私たちは学校の世界史や文学を通じて、ギリシア神話を「西洋文明の揺籃」「ヨーロッパ精神の純粋な原点」として教えられてきた。オリュンポスの十二神が織りなす整然とした体系は、いかにも理性的で調和のとれた古代ギリシアの精神を象徴しているかのように見える。

しかし、比較神話学と言語学の顕微鏡を覗き込んだとき、その「純血性」の神話はあっけなく崩壊する。

実態は真逆である。ギリシア神話とは、ステップ草原から南下してきた印欧系牧畜民の信仰が、先住のエーゲ海海洋文明（ミノア文明）、アナトリア（小アジア）、そしてシリア・レバントやメソポタミアといったオリエント先進諸文明の神々と激しく衝突し、混ざり合い、幾重にも接ぎ木された**「巨大なクレオール（混成）文化」**の産物なのだ。

オリュンポスの神々の名簿を点検してみよう。  
驚くべきことに、十二神の中で純粋に印欧祖語の語源が確定している神は、ほんの一握りにすぎない。

| 神格名 | 起源・語源の言語系統 | 本来の性格と背景 |
| :--- | :--- | :--- |
| **ゼウス（Zeus）** | **印欧系**（`*dyēus`） | 「輝く昼の空」。草原の天空父が雷霆を身にまとった姿。 |
| **ヘスティア（Hestia）** | **印欧系**（`*wes-`） | かまどの火の女神。火の祭祀。 |
| **アテナ（Athena）** | **非印欧系（プレ・ギリシア）** | アテナイの地名に由来。ミノア宮殿の「蛇の地母神・都市守護神」の継承。 |
| **アフロディーテ（Aphrodite）** | **西セム（近東）系** | フェニキアのアシュタルト、メソポタミアのイシュタルが海を渡った姿。 |
| **アポロン（Apollo）** | **アナトリア（小アジア）系** | ヒッタイトの神アプルナス（Apaliunas: 疫病と防防の神）に由来する可能性が高い。 |
| **アルテミス（Artemis）** | **非印欧系（リュディア等）** | アナトリアのエフェソスに代表される、無数の乳房を持つ豊穣の野獣女神。 |
| **ディオニュソス（Dionysos）** | **トラキア／アナトリア系** | 熱狂と酩酊、ブドウ栽培の神。外部から侵入してきた異邦の神。 |

## 海を渡った愛の女神、宮殿を守る蛇の女神

もっとも劇的な混交の例が、美と愛の女神**アフロディーテ**である。

ギリシア神話において、彼女は「切り落とされたウラノスの男根が海を漂い、その泡（アフロス）から生まれた」と語られる。そして彼女が最初に漂着した島こそが、地中海東部の**キプロス島**である。

これは神話学者にとって、あまりに露骨な「航路の記録」である。キプロスは古代、メソポタミアやシリアのセム系商人（フェニキア人）が銅の交易のために行き交った中継地であった。メソポタミアの愛と戦争の女神**イシュタル**、セム族の**アシュタルト**が、フェニキアの商船に乗ってキプロスに上陸し、そこでギリシア人の世界観と融合してアフロディーテへと変貌したのだ。彼女の従者であるエロス（クピド）や、彼女が愛した美少年アドニス（セム語で「主」を意味する Adon に由来）の存在は、そのオリエント起源を雄弁に物語っている。

また、知恵と戦争の女神**アテナ**も同様である。彼女の名前「アテナ（Athēnē）」はギリシア語では語源が解釈できない。ギリシア人が南下してくる以前、クレタ島を中心とするミノア文明の宮殿遺跡からは、両手に蛇を掲げ、胸を露わにした「蛇の地母神」の小像が大量に出土している。アテナが常に「アイギス（山羊皮の盾）」に蛇頭のメドゥーサの首を掲げ、知恵の象徴として蛇を従えているのは、彼女が先住の宮廷守護地母神の直系の子孫だからである。

北方からやって来た父権的な印欧語族の戦士たちは、征服した土地の強力な女神たちを消滅させることができなかった。  
彼らにできたのは、アテナを「ゼウスの頭から生まれた娘」と設定し、アフロディーテを「ウラノスの泡から生まれた娘」と設定することで、**自らの父系神話のネットワークの中へと力づくで養子縁組（包摂）すること**だけであった。

## クレオール文化としての神話

生物学において、孤立した閉鎖的環境で近親交配を繰り返す個体群は、遺伝的多様性を失って絶滅への道を辿る。逆に、外部からの遺伝子の流入（遺伝子流動）を柔軟に受け入れた個体群は、環境の変化に対して強靭な適応力を発揮する。

文化もまったく同じである。

もし古代ギリシア人が、草原の神話を純粋な形のまま一字一句変えずに保存しようとしていたなら、ホメロスの叙事詩も、アテナイの悲劇も、私たちが知る豊かなギリシア神話も生まれることはなかっただろう。

彼らは、地中海の先住文明が持っていた高度な都市建築、海洋航海術、文字（フェニキア文字の借用）、そして官能的で深遠な地母神信仰を貪欲に吸収した。  
天空父ゼウスを軸に据えながら、その周囲に地中海・オリエントの無数の神々を「家族」として配置したのである。

神話とは、純血の血統書ではない。  
異なる文明の波がぶつかり合う海岸で、打ち寄せられた無数の流木を組み合わせて作られた、逞しい**「クレオール（混淆）のモザイク建築」**なのである。
