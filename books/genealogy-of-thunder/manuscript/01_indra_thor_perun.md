# 第1章　インドラ、トール、ペルーン

## 酷似する英雄神たち

比較神話学の書物を開くと、まず誰もが圧倒されるのは、ユーラシア大陸の東西にまたがる雷神たちの「あまりのそっくりさ」である。

インドの主神**インドラ**は、赤みがかった髭を蓄え、怪力無双で、神酒ソーマを樽ごと飲み干し、一度怒れば天地を揺るがす。彼の武器は職人神トヴァシュトリが鍛えた金剛杵「ヴァジュラ」であり、それは投げつければ稲妻となって敵を粉砕し、必ず神の手に戻ってくる。

北欧の**トール**を見てみよう。彼もまた燃えるような赤髭をたくわえ、豪胆にして大食漢、一撃で巨人を打ち倒す剛力無双の戦士である。小人（ドヴェルグ）が鍛えた聖槌「ミョルニル」を投げ放てば、雷光を帯びて標的を粉砕し、ブーメランのようにトールの鉄手袋へと還ってくる。ヤギが引く戦車に乗り、天空を疾駆する姿は、二頭の栗毛馬が引く黄金の戦車で天地を駆けるインドラの姿と驚くほど重なり合う。

東欧スラヴの**ペルーン**も同様だ。オークの巨木が茂る聖なる丘の頂に祀られ、赤銅色の顎髭を蓄え、斧や棍棒、あるいは「雷石（ベレンナイトや石器）」を携えて天空を翔け、悪霊や闇の勢力を打ち据える。バルト神話の**ペルクーナス**もまた、天上の金床で火花を散らしながら雷斧を振り回す。

なぜ、言語も地理も大きく異なる社会で、これほどまでに具体的な細部――赤髭、大酒呑み、鍛冶職人が作った投擲武器、車輪付きの乗り物、そして怪力無双の戦士――が一致するのだろうか。

素朴な観察者は、ここでこう結論づけたくなる。「太古の昔に存在した単一の雷神が、そのまま各地へ散らばったのだ」と。

だが、比較言語学のメスを入れると、事態はそれほど単純ではないことが明らかになる。

## 語源の系譜と機能の系譜

神話の要素を科学的に比較する際、決定的に重要な原則がある。  
それは、**「語源的に同系の神」**と、**「機能的に似通った神」**を厳密に区別することだ。

もし二つの神格が、太古の同一言語（印欧祖語）の同一単語から規則的な音韻変化を経て派生した名前を持っているなら、そこには直接的な「言語的・血統的系譜」が存在する。

その代表例が、東欧とバルトの雷神たちである。

- スラヴ語派：**ペルーン（Perun）**
- リトアニア語（バルト語派）：**ペルクーナス（Perkūnas）**
- ラトビア語（バルト語派）：**ペールコンス（Pērkons）**

言語学者たちは、これらが印欧祖語の語根 `*per-kʷu-`（打つ、叩く、あるいはオークの木）に由来することを突き止めている。雷がもっとも落ちやすい大木である「オーク（カシ類）」と、「激しく打撃を加える者」という観念が結びつき、同一の語源からこれらの雷神の名が分岐した。これは疑いようもなく、家系図のように直接つながった兄弟関係である。

ところが、インドラやトール、ゼウスをここに並べると、奇妙な断絶が現れる。

北欧の**トール（Thor / 古ノルド語: Þórr）**の名は、ゲルマン祖語の `*Þunraz`（雷鳴）に由来し、英語の thunder やドイツ語の Donner（雷）と同源である。語源的には「轟く者、轟音そのもの」を意味している。

ギリシアの最高神**ゼウス（Zeus）**は、印欧祖語の `*dyēus`（光り輝く昼の空）に由来する。ゼウスの名の真の兄弟は、トールやペルーンではなく、ローマの**ユピテル（Jupiter / *Dyēus ph₂tēr）**や、インド最古の天空神**ディヤウス（Dyauṣ）**である。

そしてインドの**インドラ（Indra）**に至っては、その語源すら定説がない。「一滴（indu）」とも「力強き者」とも言われるが、印欧祖語の確たる雷神語根とは一致しない。

| 神格名 | 所属地域・言語 | 名前の語源的意味 | 印欧祖語の推定語根 |
| :--- | :--- | :--- | :--- |
| **ペルーン / ペルクーナス** | スラヴ / バルト | 「打つ者」「オークの主」 | `*per-` (打つ) / `*perkʷu-` (オーク) |
| **トール** | ゲルマン / 北欧 | 「轟く者」「雷鳴」 | `*(s)tenh₂-` (轟く) |
| **ゼウス** | ギリシア | 「光り輝く天空」 | `*dyēus` (昼の空、輝き) |
| **インドラ** | インド（ヴェーダ） | 不詳（「雫」あるいは「剛力」） | 印欧共通語根には非直結 |
| **タルフンナ** | アナトリア（ヒッタイト） | 「征服する者」「打ち勝つ者」 | `*terh₂-` (打ち破る、越える) |

この表が示している事実は決定的だ。

彼らは**「同じ名前の神が各地へ輸出された」のではない**。  
それぞれまったく異なる名前を持ち、語源的出自も異なる神々が、なぜか**「天空において雷を振るい、怪物を屠る赤髭の剛力戦士」という同一の機能的役割（ファンクション）を演じている**のである。

## 家系図ではなく「進化系統樹」

ここから、本書を通じて用いる重要な思考モデルが立ち現れる。

神話の歴史は、人間の一族のような一本道の「家系図」ではない。むしろ生物の**「進化系統樹」**に近い。

生物学において、鳥の翼とコウモリの翼は、骨格の相同性（共通祖先からの遺伝）を持ちつつも、飛行という機能に適応するためにそれぞれ独立して発達した（相似・収斂進化）。また、原核生物の間では「遺伝子の水平伝播」によって、まったく別の系統の細菌同士が有用な遺伝子モジュールをやり取りする。

神話もまったく同じだ。

神格とは、一度生まれたら不変の彫像ではない。  
それは「名前」「機能」「物語」「祭祀儀礼」という複数のパーツ（モジュール）が組み合わさった束である。

- ある地域では、古い「天空の神」が、新しく台頭した「雷の武器」というモジュールを取り込んだ（ギリシアのゼウス）。
- 別の地域では、「雷鳴」そのものを指す自然現象の言葉が人格化され、戦士の物語モジュールと融合した（北欧のトール）。
- また別の地域では、オークの木と落雷を結びつける太古の語根が、そのまま国家の守護軍神へと成長した（スラヴのペルーン）。

彼らは同じ血を引くクローンではない。  
しかし、彼らが共有する「骨格」――戦士が雷霆を振るい、自然界の混沌を打ち破るという物語の文法――は、驚くほど強固に保たれていた。

では、なぜそれほどまでに異なる出自の神々が、同一の「雷神」という鋳型へと収斂していったのか。  
その謎を解く鍵は、神々の世界の頂点に君臨していた、もう一つのより古い存在――「天空の父」との関係にある。
