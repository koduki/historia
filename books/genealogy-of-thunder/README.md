# 雷神の系譜 ――インドから北欧まで、神話が語るユーラシア人類史

## はじめに：本書の問いと中心命題

インドラ、トール、ペルーン、ゼウス。

ガンジス川の畔からスカンディナヴィアのフィヨルド、東欧の鬱蒼たるオークの森、そしてエーゲ海の島々に至るまで、数千キロメートルを隔てた古代ユーラシア大陸の諸文明には、驚くほど酷似した神話のパターンが刻まれている。

天空に咆哮し、雷霆（いかずち）を携えた戦士神が、世界を脅かす巨大な蛇や竜と対峙し、これを撃滅して「水」と「豊穣」を大地に解放する――。

なぜ、言語も地理も隔絶した遠く離れた民族たちが、これほどまでに似通った神話を語り継いだのだろうか。彼らは単に同じ一つの「原初の神」の記憶を、頑なに守り続けていただけなのだろうか。

本書の中心命題は、その素朴な前提を覆すところから出発する。

> **インド・ヨーロッパ語族は、神話を「保存」したのではない。**  
> **各地の土着社会と激しく混ざり合いながら、世界を理解し秩序づける“神話の文法”を広げたのである。**

雷神は、その移動と変容のプロセスが最もくっきりと残された**「文化の生きた化石」**である。

---

## 本書の視座：神話学から「人類史」へ

本書は、単なる「世界各地の雷神カタログ」ではない。雷神という一本の赤い糸を手繰り寄せることで、草原の遊牧民がユーラシア大陸を席巻し、各地の定住農耕民と混交しながら現代の世界文明の基盤を築いていった巨大なドラマを追体験する人類史の試みである。

そのために、本書では従来の神話学の枠組みを越え、以下の複合的アプローチを統合する。

1. **比較神話学・言語学**：神々の名前の語源（共通祖先）と、獲得された機能（水平伝播・平行進化）を峻別する。
2. **考古学・技術史**：車輪付き車両、馬の家畜化、青銅器といった「神話と信仰を運んだハードウェア」を追う。
3. **古代DNA・集団遺伝学**：ステップ草原のヤムナヤ文化をはじめとする人々の移動、父系親族の拡散、そして先住集団との混血の実態を科学的に捉える。
4. **気候史・生態学**：なぜユーラシアのステップ気候において、雷雨が単なる「天変地異」ではなく「富（草・牛・生命）の再生」を意味したのかを解き明かす。
5. **社会人類学**：三機能体系（祭司・戦士・生産民）からカースト制の形成、ゾロアスター教の宗教改革、一神教による雷神属性の吸収、そして「不滅の名声」を求める戦士倫理の深層を解剖する。
6. **文化進化論**：神話を生態系やモジュール構造として捉え、「なぜこの神話体系が数千年の風雪を耐えて現代のポップカルチャーにまで生き残ったのか」に答える。
