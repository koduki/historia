# ヤマト王権のルーツ ――なぜ皇祖は「大和の外」から来たのか

## 本書の問い

ヤマト王権は大和で成立した。

これは、纒向遺跡や初期前方後円墳をはじめとする考古学的成果から見て、もっとも自然な理解である。

ところが、その王家自身が残した神話は奇妙だ。

皇祖は大和で生まれていない。

天孫は九州南部の日向へ降り、阿多の姫と婚姻し、その子孫は海神の娘・豊玉姫を娶る。そして神武は日向を発ち、瀬戸内海を東へ進み、大和を征服する。

なぜ、大和を本拠とした王権が、自分たちを「大和の外からやって来た者」として描いたのか。

これは単なる創作なのだろうか。

それとも、ヤマト王権を構成した大王一族のどこかに、本当に西方・九州・海洋世界につながる祖先の記憶があったのだろうか。

本書では、この疑問を手掛かりとして、邪馬台国、狗奴国、南九州、隼人、海人集団、出雲、吉備、三輪、宇佐八幡までを一つの歴史として読み直す。

目指すのは「神武東征は史実だった」と証明することではない。

むしろ問いたいのは、

**史実ではなさそうな神話の中に、なぜその土地、その婚姻、その敵、その移動方向が選ばれたのか。**

ということである。

### 本書の読み方――史料と仮説の境界

本書は、以下に提示する復元像を、確定した史実として証明するものではない。文字史料の乏しい古代について、考古資料、同時代史料、後世に編纂された神話、比較神話学を重ね、その隙間をもっとも一貫して説明できる歴史モデルを提示する試みである。

そのため、本文では次の四段階をできる限り区別する。

1. **確認できる事実**――遺跡・遺物や現存史料から直接確認できること。
2. **研究上の解釈**――複数の研究者によって論じられているが、なお異説のあること。
3. **本書の仮説**――複数の断片を結ぶため、本書が独自に提示する復元。
4. **物語的な再構成**――仮説が正しいなら、どのような人間の経験が背後にあったのかを描く試み。

仮説であることは、語る価値が低いという意味ではない。むしろ、どこまでが地面から掘り出された事実で、どこからが推理なのかを明らかにしたうえで、史料の沈黙する場所へ踏み込むことこそ、本書の古代史ロマンである。

## 本書の分析視座（三つの時間層と世界史的視点）

本書では、時代錯誤（アンクロニズム）を徹底して排除するため、以下の三つの時間層を峻別して論述を進める。

1. **【第1層：初源の事実・現実】（2〜4世紀：弥生末期〜古墳前期）**
   - 纒向を中心とする大和盆地における多地域首長連合の出現。
   - 九州南部・瀬戸内・吉備・東海などの自立的文化圏と、特定首長家による西方・海洋ネットワークへの関与。
2. **【第2層：記憶・伝承の形成】（5〜6世紀：古墳中期〜後期・氏族社会）**
   - 前方後円墳体制の展開と大王家の確立。
   - 各氏族（吉備、阿曇、物部、出雲等）における個別祖先伝承（『帝紀』『本辞』の祖型）の形成。
3. **【第3層：国家正史の編纂】（7〜8世紀：天武・持統朝〜律令国家期）**
   - 壬申の乱、白村江の敗戦、律令制導入という国家的危機。
   - 南九州（隼人）統合と720年「隼人の乱」という同時代の政治課題。
   - 『古事記』『日本書紀』における「余所者伝承」の普遍王権化（天孫降臨・神武東征神話の完成）。

さらに、日本古代史の枠内に閉じず、**外来王（Stranger-King）論**（M・サーリンズ）、**文化的記憶論**（J・アスマン）、**比較神話学**（吉田敦彦等）の視座を導入し、人類史的な普遍的王権形成のダイナミズムとして解き明かす。
