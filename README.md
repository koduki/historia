## 開発・執筆ガイド

### 前提条件
- Node.js (v20以上推奨)

### ローカルプレビュー
各作品をローカルサーバーで確認できます：

```bash
# 「ヤマト王権のルーツ」をプレビュー
npm run serve:yamato

# 「雷神の系譜」をプレビュー
npm run serve:thunder

# 任意の作品ディレクトリを指定してプレビュー
npm run serve -- books/<作品フォルダ名>
```

ブラウザで `http://localhost:4000` を開くとプレビューが表示されます。

### 全作品のビルド
すべての作品を `_book/<slug>/` にビルドし、トップページ（`_book/index.html`）を生成します：

```bash
npm run build
```

### 新しい作品の追加方法
1. `books/_template/` フォルダを `books/<新しい作品スラッグ>/` にコピーします。
2. `book.json` の `title`, `description` などを編集します。
3. `SUMMARY.md` と `manuscript/` 配下に原稿を作成します。
4. `npm run build` を実行すると、自動的に作品が認識され、ポータルサイトにも追加されます。
